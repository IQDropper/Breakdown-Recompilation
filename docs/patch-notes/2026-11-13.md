# Breakdown PC - Update notes: from the developer tools to now

The game's own hidden debug menus are back, and a full set of PC settings, accessibility options and testing
tools grew from them.
Laptops now run the game on their fast graphics chip, and a finalized **Recommended** preset gives the best look in
one press.
HD textures are under way: AI upscaling with a check for made-up text, and the whole game's textures can now be
pulled from the game files.
For modders and testers: the level files are readable (every checkpoint, loading zone and enemy spawn), plus a damage log.

Covers PRs #25 to #49 (2026-11-11 to 2026-11-13). PR #50 is listed under "Coming next" (not merged yet).
Unless a line says otherwise, everything new is off until you turn it on.

---

## How to change settings

Open the **PC options page** with **F10**, or hold **Back** and press **Start** (Backspace + Enter on a keyboard).
Up / Down picks a row, Left / Right changes it, **Apply** saves it to `breakdown_video.cfg`.
Rows added in this period: **VSync**, **Wide view**, **Hold to repeat**, **Hold toggle**, **Outfit**, **Text size**,
**Mouse speed**, **Invert mouse**, **Stick dead zone**, **Keys**, and the **Recommended** button.

## Graphics and performance

- **Fixed:** on laptops with two graphics chips, the game ran on the slower built-in one. It now asks Windows for the
  fast chip. Measured on the dev laptop at 4x resolution, all gameplay:
  - Median frame time decreased from 37.0 ms to 33.3 ms (-10%).
  - Worst 1% frame time decreased from 58.2 ms to 36.9 ms (-37%, far fewer hitches).
  - Frame rate increased from 27.1 to a locked 30.0 FPS.
- **Fixed:** exclusive fullscreen fell back to a window on a second monitor. It now works on both screens, and if it
  ever fails the log says why.
- **Fixed:** at internal resolution 1x the picture filled only the top-left quarter of the window. It now fills it.
- **New: Hor+ widescreen.** In 16:9, 16:10 or 21:9 you see more of the room at the sides instead of black bars.
  The HUD, menus and movies stay 4:3 in the middle.
- **New: Wide view row** under Aspect: **Bars** (the 4:3 picture with side bars) or **Hor+**. Hor+ was a launch switch
  only; it is now a saved setting. Takes effect the next time you start the game.
- **New: VSync row** (On / Off). Each frame waits for the screen, which stops tearing. Changes at once.
- **Checked: 1x and 4x show the same view.** An earlier comparison suggested 4x showed more of the room. Taken from the
  same spot, both frames match edge for edge; the old pair came from two different standing positions. No change made.

### Recommended preset (finalized)

- **New: Recommended button** on the PC options page. One press sets:
  - Internal resolution: 4x
  - Present filter: Linear
  - Aspect: 16:9, Wide view: Hor+
  - 60 FPS gameplay: On
  - Don't wait for renderer: On
  - VSync: On
  Window size and mode, controls, accessibility and outfit stay as they are. **Reset** still gives the original look.
- **Behaviour change:** a first start (no settings file yet) now begins on the Recommended preset instead of the
  original 1x look. After that the file is yours.
- Measured cost on the dev laptop (doorway room, 60 FPS mode on, compared with internal 2x):
  - "Don't wait for renderer" increased the frame rate from 47.9 to 57.2 FPS (+19%); median frame time decreased from
    19.9 ms to 16.7 ms (-16%).
  - Internal 1x, 3x and 4x, the filters, VSync, window mode and Hor+ showed no measurable cost (all within the 10%
    run-to-run noise).

*Developer note: the game is limited by the processor on this laptop, not the graphics chip, so the sharpest picture
settings are free there. I approved the Recommended preset as the look for this class of PC.*

## Controls and accessibility

- **New: Keys** row: rebind every control to one or two keys (Enter opens the list, press the new key). Mouse buttons and
  controllers keep their own buttons.
- **New: Mouse speed** 50%, 75%, 100%, 150%, 200%, 300% (default 100%). **Invert mouse** On / Off.
- **New: Stick dead zone** Off, 10%, 20%, 30% (for worn or drifting sticks).
- **New: Hold to repeat** (Off, A, B, X, Y, or all four): hold the button instead of mashing; the game sees 10 presses
  a second.
- **New: Hold toggle** (Off, Right trigger, Left trigger, Both): press once to hold, press again to let go.
- **New: Text size** for the PC options page: 100%, 150% or 200%. Long lists scroll and say "more above / more below".
- **New: First-launch welcome.** The first time the game starts, the PC options page opens once with a short welcome,
  so new players find these settings.

## Outfits

- **New: Outfit row** (Game's choice, Normal, T shirt, Researcher), using outfits the game already has. Shows from the
  next time Derrick appears. Story outfits still win, and an outfit only shows where its models are loaded.

## HD textures

- **New: HD texture tools** for your own copy: dump the game's textures, upscale them, pack them, play with them
  (`docs/hd-textures.md`).
- **New: AI upscaling (4x)** with Real-ESRGAN, with safety checks: every result is shrunk back and compared with the
  original, and a mismatch is thrown out; the life bar's texture and a few special formats are never touched.
- **New: made-up text check and repaints.** Small writing the AI could not read gets invented letters. Every upscaled
  texture is reviewed side by side; those with made-up text are repainted with real wording, kept as an honest blur,
  or kept original, and each choice is written down.
  - Doorway room: 139 textures upscaled, 11 repainted (patient chart, juice can, ration pack, fire alarm, wall panel,
    EEG monitor with the 状況報告 label, and more).
  - Burger event: 57 new textures, 56 upscaled; the soldiers' gun selector (FULL / 3RD / SEMI / SAFE) and the burger
    wrapper (Terminus 4 / Project) repainted.
  - One pack for both rooms: 192 textures, 594 MB. Seen working in game: faces, HUD and subtitles intact.

*Developer note: I want "the best possible" HD look, without guessing at words the original never showed
clearly; every word is marked known, ours, or kept blurred.*

## Extras

- **New: Skip the intro movie** (`RECOMP_SKIP_INTRO=1`): the title shows 14.7 s after launch instead of after the
  ~4-minute opening movie.
- **New: F12 screenshot** (on by default; `RECOMP_SCREENSHOT=0` turns it off).
- **New: FPS counter** (`RECOMP_FPS_OVERLAY=1`, F5 shows / hides).
- **New: Speedrun timer** (`RECOMP_SPEEDRUN=1`, F11): game time only, with a split at each new area.
- **New: Combo list in the Skills panel** (`RECOMP_SKILL_COMBOS=1`): 37 combos in the game's own font and buttons.
- **New: VIDEO SETTINGS row** in the game's own Options menu (`RECOMP_VIDEO_ROW=1`), in the game's lettering.

## Developer and testing tools (opt-in)

**These are not player features.** Nothing here happens unless you set the switch. Some change balance.

### The original debug menus
- **New: Product debug menu** (F9 during the intro) and the developers' **F026 menu** (F8), with each programmer's
  test menus. These shipped in the retail game but could not be opened. Needs `RECOMP_DEBUG_MENU=1`.
- **New: Debug Mode Select** in play (F7): 25 developer switches. Three that retail left without code were rebuilt:
  - **Player NoDamage:** life stays at full.
  - **Player FastMove:** walking speed x2 (`RECOMP_FASTMOVE_SCALE`).
  - **Player Position Disp:** position and life on screen in normal play.

### Tuning window
- **New: Tuning window** (`RECOMP_TUNING=1`, F6; on a controller click both sticks): change max life, life, stamina
  and move speed while playing, mark ideals, and **Finalize** values so the game uses them every start. Only the developer
  finalizes.

### Level tools (read the game files without playing)
- **New: level event reader:** every area's trigger boxes, loads, rules, save points, objects and spawns.
  - 25 area changes (the NOW LOADING screens) and 286 quiet section loads, each with the box that starts it.
  - 192 checkpoints in story order across 22 areas, with chapter numbers 1 to 35.
- **New: level catalog:** per area, every character spawn (1,464 in the game) with its model, the developers' note
  for it, its behaviour script (1,452 named), weapon, section and position; hazards; power-up scenes.
  - **Enemies ahead of a checkpoint:** one command lists them, e.g. after the burger room, three rifle soldiers just
    past the first loading box.
- **New: pack reader:** lists the animations, models, textures, sounds and behaviour scripts inside each pack.
- **New: position log** (`RECOMP_POS_LOG=1`): Derrick's position once a second, to match places to loading zones.
- **New: damage log** (`RECOMP_DAMAGE_LOG=1`): one line every time any character's life changes, with the exact
  amount, e.g. `hero life 170.0 -> 100.0 (-70.0)`.
- **In progress: checkpoint save editor.** Lists every checkpoint and writes a correctly signed copy of a save at
  another one. The game accepts these saves and loads the new area, but the screen stays black (the save's
  story-progress record is still missing). Not usable yet; your own saves are never touched.

## Bug fixes

- Fixed the game running on the slow graphics chip on dual-chip laptops.
- Fixed exclusive fullscreen falling back to a window on a second monitor.
- Fixed the picture filling only a quarter of the window at internal resolution 1x.
- Fixed the PC options page's Aspect and Window mode help saying Hor+ was not available.
- Fixed the HD repaint tool splitting or cutting a word that was slightly too wide (e.g. "FUL / L").

## Known issues

- **Recommended preset** is measured on one laptop only (i7-9750H, GTX 1660 Ti). Weaker PCs and the Steam Deck are not
  checked; use Reset or lower Internal resolution if it runs slowly.
- **Hor+ widescreen:** on the main menu one panel sticks out past the 4:3 area on the left, and the pause menu's
  darkening covers only the middle.
- **HD textures** cover the doorway room and the burger event so far. Elsewhere you see the original textures.
- **The FPS counter** sits over the health gauge (top left).
- **Stamina** reads 0 in the first rooms; it may only start later in the story. Not checked.
- **Keyboard:** White (Q) doesn't switch lists on the Debug Mode Select page. Use a controller there.
- **Damage log** has not been seen in a real fight yet (tested by setting life directly).
- **Outfits:** T shirt looks the same as Normal in first person (same hands).

**Risks**
- #48 changes what a fresh install looks like (Recommended instead of 1x). Existing `breakdown_video.cfg` files are
  untouched; launch-script variables still win.
- #35 changes which GPU every hybrid laptop uses; an AMD laptop is untested.
- `breakdown_video.cfg` gained keys in this period: VSync, the A11Y keys, outfit, text size, mouse, dead zone, keymap,
  and `RECOMP_HORPLUS`. Older files load with defaults.
- The checkpoint save editor writes signed saves; it refuses to overwrite its input, but never point it at the real
  save folder (use `RECOMP_SAVE_DIR`).

**Caught before merge (tooling)**
- AI upscaling of one linear-format texture and the HUD sheet turned the life bar white; both are now skipped.
- The upscaler's folder mode mixed up pictures on big batches; each texture now runs on its own and is checked.

**Test checklist before sharing a build**
- [ ] Fresh setup, gate pass, boot to the title with `run_native.cmd`.
- [ ] Delete `breakdown_video.cfg` in a copy: first start writes the Recommended preset; the log says `hor+ on`.
- [ ] PC page: Recommended, Reset, every new row, Apply, restart, still set.
- [ ] Laptop: game on the fast chip; exclusive fullscreen on each monitor.
- [ ] HD pack: doorway and burger event, life bar and subtitles intact.
- [ ] Controls: rebind a key, mouse speed, dead zone on a real controller.
