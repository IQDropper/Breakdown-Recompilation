BREAKDOWN (native) - KEYBOARD + MOUSE CONTROLS
================================================
Start with run_native.cmd. A real controller still works at the same time.
After SETUP.cmd (or APPLY_INPUT_PATCHES.cmd), mouse capture is built into the toolkit.

Two mouse layouts
-----------------
MODERN (default in run_native.cmd) — FPS-style punches for Breakdown melee combos
LEGACY — older face-button mouse map (set RECOMP_MOUSE_BUTTONS=X,B,Y,LT,RT)

MOUSE (both layouts)
  Click in the game window ... grab the mouse (that click is NOT sent to the game)
  Move mouse ................ look around (right stick)
  Scroll wheel .............. D-pad up / down
  F1 ........................ release mouse (Alt-Tab also releases)

MOUSE BUTTONS — MODERN (default)
  Left click ................ Left trigger   (left punch)
  Right click ............... Right trigger  (right punch)
  Middle click .............. Y
  Side button (back) ........ White
  Side button (forward) ..... Black

MOUSE BUTTONS — LEGACY
  Left click ................ X
  Right click ............... B
  Middle click .............. Y
  Side button (back) ........ Left trigger
  Side button (forward) ..... Right trigger

PC OPTIONS (owned borderless host overlay over the 4:3 picture, not drawn into the frame, not an Xbox screen)
  Back + Start .............. opens PC options (Backspace + Enter)
  F10 ....................... same page, backup toggle
       Start alone still pauses and still advances the title.
       Internal resolution, window size, letterbox aspect (4:3, 16:9,
       16:10, 21:9), present filter, window mode (windowed, borderless, exclusive).
       Apply writes breakdown_video.cfg. Reset previews stock.
       Esc, B, or Revert puts the picture back.
       A row marked "launch script" follows that RECOMP_* variable.
       Hor+ is not on this page. Exclusive needs the D3D11 patch; Alt+Tab leaves it.
       Details: docs/video-options.md

EXTRAS (host keys, only while the game window is in front)
  F12 ....................... screenshot (PNG of the 4:3 picture) to
                              %LOCALAPPDATA%\xboxrecomp\screenshots\breakdown_<date>_<time>.png
                              (set RECOMP_SCREENSHOT=0 to turn F12 off)
  F5 ........................ show/hide the FPS box (needs RECOMP_FPS_OVERLAY=1):
                              average FPS and frame time over the last second, slowest frame
  RECOMP_SKIP_INTRO=1 ....... skip the 2 minute opening movie at boot (the logos still play)
  Outfit (PC options page) .. Derrick's outfit: Game's choice, Normal, T shirt or Researcher
                              (RECOMP_HERO_OUTFIT=normal|t|researcher). Shows from the next time he
                              appears (load a save). Story outfits still win, and an outfit is only
                              used where the game has its models loaded (T shirt: the opening area;
                              Researcher: the lab). In first person only the hands show (hold Shift).
  First launch .............. the PC options page opens once by itself, pointing at Text size, the Hold
                              options and Keys. RECOMP_FIRST_LAUNCH=0 never shows it, =1 every launch.
  Mouse speed (PC options) .. 50% to 300% look speed (RECOMP_MOUSE_SENS, 1200 = 100%). Changes at once.
  Invert mouse .............. On: moving the mouse up looks down (RECOMP_MOUSE_INVERT).
  Content ................... Classic (default): the original game. New: our added content (hidden lines
                              in the HD textures, flash scares, new moves). Fixes stay on in both.
                              Textures switch on the next start (RECOMP_CONTENT=classic|new).
  Stick dead zone ........... Off, 10%, 20%, 30%: ignore small stick movement (RECOMP_PAD_DEADZONE).
  Keys (PC options) ......... Enter opens the key list: every control with its key(s). Enter on a control,
                              then press the new key. Delete puts its default back, Esc returns to the
                              page, Apply saves (RECOMP_KEYMAP, e.g. LT=1|Q;RT=3|E).
  Text size (PC options) .... 100%, 150% or 200% text on the PC options page (RECOMP_PC_TEXT_SIZE).
                              It also grows with the window. When the rows do not all fit, the list
                              scrolls with the selection and says "more above / more below".

KEYBOARD (same in both layouts)
  W A S D ................... move (left stick)
  I J K L ................... look (right stick), if you prefer keys
  Z / X / C / V ............. A / B / X / Y
  Q / E ..................... White / Black
  1 / 3 ..................... Left trigger / Right trigger (punch keys)
  Enter ..................... START (pause)
  Backspace ................. BACK
  Arrow keys ................ D-pad (menus)
  Shift / Ctrl .............. left / right stick click

CHANGE THE MOUSE (edit run_native.cmd, the "set RECOMP_MOUSE..." lines)
  RECOMP_MOUSE_SENS=1200 .... look speed (higher = faster)
  RECOMP_MOUSE_INVERT=1 ..... flip up/down look
  RECOMP_MOUSE_BUTTONS=LT,RT,Y,WHITE,BLACK   ... Modern
  RECOMP_MOUSE_BUTTONS=X,B,Y,LT,RT           ... Legacy
       order: left, right, middle, back side button, forward side button
       names: A B X Y WHITE BLACK LT RT START BACK LS RS UP DOWN LEFT RIGHT NONE
  RECOMP_MOUSE=0 ............ turn the mouse off

If mouse does nothing after a toolkit reinstall, run APPLY_INPUT_PATCHES.cmd then rebuild.
